# Simple Next.js Site

A minimal Next.js (App Router) + Tailwind CSS starter — one homepage, no
extra dependencies.

## Run it locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Where to edit

- `app/page.js` — all page content
- `app/layout.js` — page title/description, global wrapper
- `tailwind.config.js` — colors (`ink`, `paper`, `moss`, `gold`) and fonts
- `app/globals.css` — global styles, font import

## Build for production

```bash
npm run build
npm run start
```
